On a related note on the “CVE scan”:

> The CVE scanner might show false positives for the following reasons:
>
> - The scanner does not check whether the vulnerability actually exists.
> - The scanner has no capabilities to detect “backported” security fixes, for example on Unix-like systems, because it depends on the <a href="https://nvd.nist.gov/" rel="noopener nofollow ugc">National Vulnerability Database (NVD)</a>, which does not maintain this fixed status and because there is no exposure of the fixed status in the version of the product.
>
